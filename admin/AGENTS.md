# Admin Panel

## Commands

| Command | Script |
|---------|--------|
| dev | `npm run dev` |
| build | `npm run build` (typechecks + builds) |
| lint | `npm run lint` |

## Stack

Next.js 16 App Router + React 19 + Tailwind CSS v4 (via `@tailwindcss/postcss`) + TypeScript. Separate `package.json` from other apps.

## Features

Admins can:

- Manage users
- Manage employees
- Manage clients
- Manage services
- Manage projects
- Generate invoices
- Send notifications
- Publish blog posts
- Manage portfolio
