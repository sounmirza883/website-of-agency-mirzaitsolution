# Client Portal

## Commands

| Command | Script |
|---------|--------|
| dev | `npm run dev` |
| build | `npm run build` (typechecks + builds) |
| lint | `npm run lint` |

## Stack

Next.js 16 App Router + React 19 + Tailwind CSS v4 (via `@tailwindcss/postcss`) + TypeScript. Separate `package.json` from other apps.

## Features

Clients can:

- View projects
- Track progress
- Download files
- View invoices
- Pay invoices
- Open support tickets
- Chat with your team
