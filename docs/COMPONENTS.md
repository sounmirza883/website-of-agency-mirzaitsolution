# Components

## There is no design system

The web portals export exactly two shared things. Every modal, table, page header, status pill and button is copy-pasted Tailwind. When adding UI, **copy the canonical block** listed below rather than inventing a variant.

Because the apps are separate packages with no shared library, a shared component must be **duplicated into each app**. `Field` exists three times, once per portal.

## Web — shared exports

Both `frontend/admin/app/components.tsx` and `frontend/employee/app/components.tsx`:

```tsx
export const fieldClass = "w-full px-3 py-2 border border-gray-200 rounded-lg text-sm";

export function Field({ label, children }: { label: string; children: React.ReactElement<{ id?: string }> }) {
  const id = useId();
  return (
    <div>
      <label htmlFor={id} className="block text-xs font-medium text-gray-500 mb-1">{label}</label>
      {cloneElement(children, { id })}
    </div>
  );
}
```

`Field` takes **exactly one** child and injects `id` via `cloneElement`, so the label is genuinely associated — clicking it focuses the control. To wrap a conditional, render the branch inside as a single element.

The client portal has the same component rendering inline styles instead of classes, matching local convention, and exports `inputStyle` rather than `fieldClass`.

Also module-private in each: `ChangePasswordModal`, the `nav` array, and the shell (`AdminShell` / `EmployeeShell` / `ClientShell`).

## Canonical markup to copy

**Modal** — `frontend/employee/app/leave/page.tsx`. No portal, no `<dialog>`, no focus trap. A fixed overlay that closes on backdrop click; the `<form>` is the panel and calls `stopPropagation`.

```tsx
<div className="fixed inset-0 bg-black/30 flex items-center justify-center z-50 p-4" onClick={close}>
  <form onSubmit={handleSubmit} onClick={(e) => e.stopPropagation()} className="w-full max-w-md bg-white rounded-xl p-6">
    <h2 className="text-lg font-bold mb-4">Title</h2>
    {error && <div className="mb-4 text-sm text-red-600 bg-red-50 px-3 py-2 rounded-lg">{error}</div>}
    <div className="space-y-3">{/* <Field> per input */}</div>
    <div className="flex justify-end gap-2 mt-6">
      <button type="button" onClick={close} className="px-4 py-2 text-sm text-gray-600 hover:text-gray-900">Cancel</button>
      <button type="submit" disabled={m.isPending} className="bg-accent text-gray-50 text-sm font-medium px-4 py-2 rounded-lg disabled:opacity-50">
        {m.isPending ? "Creating…" : "Create"}
      </button>
    </div>
  </form>
</div>
```

Pending labels are present participles with an ellipsis character `…` (U+2026), not three dots.

**Table** — `frontend/employee/app/attendance/page.tsx`. Headers are generated by mapping a string array; a trailing `""` header marks an actions column.

```tsx
<div className="bg-white rounded-xl border border-gray-200 overflow-x-auto">
  <table className="w-full text-sm">
    <thead><tr className="bg-gray-50 text-left">{HEADERS.map((h) => <th key={h} className="px-5 py-3 font-medium text-gray-600">{h}</th>)}</tr></thead>
    <tbody>{/* rows */}</tbody>
  </table>
  {rows?.length === 0 && <div className="px-5 py-8 text-center text-sm text-gray-400">No X yet</div>}
</div>
```

Cells: first `px-5 py-3 font-medium`, text cells `px-5 py-3 text-gray-600`. Status pill `text-xs font-medium px-2 py-0.5 rounded` plus a `bg-*-100 text-*-700` ternary. Row action `text-xs text-gray-600 hover:text-gray-900 border border-gray-200 rounded-md px-2 py-1`; destructive swaps to red.

**Page header**

```tsx
<div className="flex items-center justify-between mb-6">
  <div>
    <h1 className="text-2xl font-bold mb-1">Title</h1>
    <p className="text-sm text-gray-500">Subtitle</p>
  </div>
  <button className="bg-accent text-gray-50 text-sm font-medium px-4 py-2 rounded-lg">+ Add Thing</button>
</div>
```

Create buttons are prefixed with a literal `+ `. Admin uses `bg-accent`, employee `bg-accent-2`.

**Stat card**

```tsx
<div className="bg-white rounded-xl border border-gray-200 p-5">
  <div className="text-2xl font-bold text-gray-900">{value}</div>
  <div className="text-sm text-gray-500 mt-1">{label}</div>
</div>
```

**Progress bar** — the only one in admin/employee, hand-rolled at `employee/app/status/page.tsx`:

```tsx
<div className="w-full bg-gray-100 rounded-full h-2 mb-3">
  <div className="bg-blue-600 h-2 rounded-full" style={{ width: `${progress}%` }} />
</div>
```

No component, no ARIA, no clamping. If you need a second one, extract it into `components.tsx` in each portal.

## Drag and drop

`@dnd-kit/react` v0.5 — not the classic `@dnd-kit/core`. `useDraggable({ id, data })` → `{ ref, isDragging }`; `useDroppable({ id, data })` → `{ ref, isDropTarget }`; handler reads `event.operation.source?.id` and `event.operation.target?.id`, guarding `event.canceled`.

To put an interactive control on a draggable card, stop pointer events reaching dnd-kit:

```tsx
<div onPointerDown={(e) => e.stopPropagation()}>{/* select, button */}</div>
```

Without it the control cannot be opened.

| Component | Props |

| `Field` | `{ label } & TextInputProps` — label, themed placeholder colour, `accessibilityLabel` |

Exported style constants live in `forms/field.tsx`: `inputClass`, `labelClass`, `placeholderColor`.

`DateField` uses platform-specific files (`.ios.tsx`, `.android.tsx`, plus a web fallback) with shared pieces in `date-field-shared.tsx` — importing `./date-field` from inside `date-field.ios.tsx` would resolve back to itself, so shared code must live under a different module name.

## Form labelling rule

**Every input carries a visible label.** Placeholders vanish the moment you type, and date, select and file controls never show one at all — a bare `<input type="date">` renders as an unexplained `mm/dd/yyyy` box.

Use `Field`. Reserve placeholders for format hints that add information beyond the label (`e.g. $199`), not for repeating it.
